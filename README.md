# Programmation Web Frontend — Résolutions des labos

Ce dépôt contient les résolutions des labos réalisés durant les sessions de formation du cours **Programmation Web Frontend**, destiné aux apprenants de 2ème année de la formation **UX/UI Designer** de l'IFAPME.

## Organisation

Les labos sont regroupés par session de formation :

```
session-1/
  labo-2/
    labo-2-1.js
    labo-2-2.js
    ...
session-2/
  labo-1/
  labo-2/
  ...
```

- Un dossier `session-N/` par session de formation.
- Un dossier `labo-X/` par labo vu durant la session.
- Un fichier `labo-X-Y.js` par exercice du labo.

Les exercices sont écrits en JavaScript « vanilla », sans dépendance ni étape de compilation. Les résultats sont affichés dans la console via `console.log`.

## Exécuter un exercice

Avec [Node.js](https://nodejs.org/) installé, depuis la racine du projet :

```sh
node session-2/labo-1/labo-1-1.js
```

Dans VS Code, l'extension **Code Runner** permet aussi d'exécuter le fichier ouvert directement dans le panneau de sortie.
