# Exercices supplémentaires

Des exercices pour s'entraîner en dehors des labos. Chaque série reprend les notions déjà vues au cours, et rien d'autre.

| Série | Fichier | Notions | Prérequis |
|---|---|---|---|
| 1 | [exercices-1.md](exercices-1.md) | console, expressions, commentaires, variables, types, conversions | Sessions 1 et 2 |

## Comment travailler

1. Créez un dossier `solutions-N` (N = numéro de la série), par exemple `solutions-1/`.
2. Créez un fichier par exercice : l'exercice 1-3 va dans `solutions-1/solution-1-3.js`.
3. Commencez chaque fichier par ce bloc, complété :

   ```js
   /*
     Exercice 1-3
     Auteur : Prénom Nom
     Date : 2026-10-01
   */
   ```

4. Exécutez votre fichier :

   ```sh
   node solutions-1/solution-1-3.js
   ```

5. Comparez votre sortie avec la **sortie attendue** de l'énoncé. Elle doit être identique, caractère par caractère : espaces, majuscules, ponctuation.
6. Cochez la liste **« Avant d'envoyer »** de l'exercice.
7. Envoyez le dossier `solutions-1/` complet à votre formateur.

## Lire un énoncé

Chaque exercice suit le même plan :

- **Niveau** : 1 · Simple, 2 · Modéré ou 3 · Avancé, comme pendant les labos.
- **Contexte** : la situation de départ.
- **Données** : les valeurs à utiliser, exactement telles qu'écrites.
- **Consignes** : les étapes, dans l'ordre.
- **Sortie attendue** : ce que votre programme doit afficher.
- **Avant d'envoyer** : la liste des points que votre formateur va vérifier.

## Règle du jeu

Uniquement ce qui a déjà été vu au cours. Pour la série 1 : pas de `if`, pas de boucle, pas de fonction, pas de liste, pas de `Math`, pas de `var`.

Une sortie correcte ne suffit pas : le code doit aussi respecter les consignes (bons types, `const` ou `let` justifiés, calculs faits par le programme et pas à la main).
